Podium L4C84L · bouton MyEasyOptic

1. Installer le bouton (une fois par poste)

  1. Affichez la barre de favoris de Chrome : Ctrl + Maj + B.
  2. Faites glisser ce bouton dans la barre de favoris :
    → Podium

Ne cliquez pas dessus ici : il ne fonctionne que sur l'écran de vente / devis de MyEasyOptic.

2. Utilisation

  1. Dans MyEasyOptic, ouvrez le devis du client (ordonnance et monture saisies).
  2. Cliquez sur → Podium dans la barre de favoris : Podium s'ouvre avec la correction et le prix de la monture.
  3. Complétez les mesures, présentez les verres, sélectionnez le verre choisi (bandeau bleu de la vignette).
  4. Cliquez sur Envoyer dans MyEasyOptic : le libellé du verre est collé dans le devis et la recherche s'ouvre.
  5. Dans MyEasyOptic, cliquez sur la ligne exacte, choisissez le diamètre, puis OK.

Aucune donnée client ne passe par un serveur : l'échange se fait directement entre les deux onglets du navigateur. Si Chrome bloque l'ouverture de Podium, autorisez les fenêtres pop-up pour MyEasyOptic.
