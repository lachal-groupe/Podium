Podium L4C84L · extension MyEasyOptic

1. Installer l'extension (une fois par poste)

  1. Téléchargez l'extension :
    Télécharger extension-podium.zip
  2. Dans l'Explorateur Windows, faites un clic droit sur le fichier → Extraire tout… et placez le dossier extension-podium à un endroit fixe (par exemple Documents). Ne le supprimez plus ensuite.
  3. Dans Chrome, ouvrez l'adresse chrome://extensions (copiez-la dans la barre d'adresse).
  4. En haut à droite, activez le Mode développeur.
  5. Cliquez sur Charger l'extension non empaquetée et choisissez le dossier extension-podium.
  6. L'extension « Podium L4C84L pour MyEasyOptic » apparaît : c'est prêt. Rechargez MyEasyOptic s'il était ouvert.

Mise à jour : téléchargez la nouvelle version, remplacez le contenu du dossier, puis cliquez sur la flèche ↻ de l'extension dans chrome://extensions.

2. Utilisation

  1. Dans MyEasyOptic, ouvrez le devis du client (ordonnance et monture saisies).
  2. Cliquez sur le bouton bleu Podium affiché à droite de l'écran du devis : Podium s'ouvre avec la correction et le prix de la monture.
  3. Complétez les mesures et le type de monture, cliquez sur Voir les verres, présentez le podium.
  4. Sélectionnez le verre choisi (bandeau bleu de la vignette) puis Envoyer dans MyEasyOptic.
  5. MyEasyOptic revient avec le verre présélectionné : choisissez le diamètre puis OK. Le Précalibrage se coche au retour sur le devis.

Aucune donnée client ne passe par un serveur : l'échange se fait directement entre les deux onglets du navigateur. Si Chrome bloque l'ouverture de Podium, autorisez les fenêtres pop-up pour MyEasyOptic.

Dépannage : bouton de la barre de favoris

Sur un poste où l'extension ne peut pas être installée, ce bouton fait la même chose depuis la barre de favoris (Ctrl + Maj + B pour l'afficher).
